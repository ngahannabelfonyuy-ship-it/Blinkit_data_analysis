# Blinkit_data_analysis
Exploratory data analysis of the blinik data set using python# Blinkit Data Analysis (Python)

## Project Overview
This project focuses on exploratory data analysis (EDA) of the Blinkit dataset using Python.  
The goal was to understand sales behavior, improve data consistency, and extract meaningful insights.

## Objectives
- Understand the structure and features of the dataset
- Resolve data inconsistencies to improve data quality
- Identify sales patterns and trends
- Visualize insights for clear communication

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Steps
1. Data exploration and understanding  
2. Data cleaning (handling inconsistencies)  
3. Exploratory Data Analysis (EDA)  
4. Data visualization  

## Key Insights
- Sales performance varied significantly across outlet types and sizes
- Certain product categories consistently contributed more to total sales
- Outlet characteristics had a strong influence on overall performance
